# Loot & prices

Defaults live in `shared/loot.lua`. You can change pools live with the [loot editor](./loot-editor). Sale prices are always set in `Loot.Items`.

::: info Weights are relative
Weights are whole numbers compared with each other, not percentages. If two items have weights 30 and 70, their chances are 30% and 70%.
:::

## Editing defaults in code

```lua
Loot.Items['kb3_gold_ring'] = { label = "Gold Ring", price = 1800, weight = 20, tier = 'rare' }

Loot.Ground = {
    { item = 'kb3_bottle_cap', weight = 140 },
    -- ...
}

Loot.Bags = {
    rare = { {'gold_ring',30}, {'gold_chain',25}, {'antique_compass',25}, {'luxury_watch',12}, {'gold_coin',8} },
    -- bag entries omit the kb3_ prefix
}
```

Keep every loot item defined in your inventory with a matching image. Item IDs, `Config.ItemPrefix`, bag mappings and your install snippet must all agree.
