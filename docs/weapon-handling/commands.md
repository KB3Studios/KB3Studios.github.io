# Commands & controls

| Command / control | Action |
| --- | --- |
| `/slingmenu` or `/slingedit` | Open the [placement editor](./editor) (standing still, on foot) |
| <kbd>Left Ctrl</kbd> | Toggle crouch (rebindable as *KB3: toggle crouch*) |
| `/kb3standup` | Cancel a pending crouch and reset crouch movement |
| `/gunrun`, `/gunrun on`, `/gunrun off` | Change the lowered carry preference |
| `/sling front` / `/sling back` | Set your default carry side. Saved per-weapon choices take priority |
| `/sling hide` / `/sling show` | Hide or show your sling props |
| `/slingclose` or `/kb3uiclose` | Close the UI and camera and discard the preview |
| `/slingadmin WEAPON_NAME front` | Admin shared-default editor. Use `back` or `hip` as appropriate |
| `/slingdebug` | Print sling diagnostics to F8 |
| `/crouchdebug` | Print crouch diagnostics to F8 |

`/slingadmin` requires the `kb3_weaponhandling.admin` ACE.
