# Getting support

Join the **[KB3 Studios Discord](https://discord.gg/vRqEgswrng)** and open a ticket. For purchases, downloads and licence questions, visit the **[KB3 Studios store](https://kb3-studios.tebex.store/)**.

## Include this in your ticket

To get a fast answer, include:

- **Resource and version**, for example *KB3 Metal Detecting 1.2.2*
- **Framework**: Qbox, QBCore or ESX Legacy, and its version
- **Inventory** and its version
- **The exact error text** from the server console or F8, copied rather than screenshotted where possible
- **Steps to reproduce** the problem

Resource-specific extras:

| Resource | Also include |
| --- | --- |
| Admin Panel | The **Integrations** card from **Server health**, plus any `[KB3 Admin Panel]` console lines |
| Lean | The output of `/leandiag` |
| Weapon Handling | The F8 output of `/slingdebug` or `/crouchdebug` |
| Metal Detecting | Your `Config.Framework` and `Config.Inventory` values |
| Nova HUD | The F8 start-up lines (seatbelt mode, postals loaded), and `/hudveh` output for vehicle light issues |

::: danger Never post secrets
Don't post database passwords, server keys, webhook URLs or player data in public channels.
:::
